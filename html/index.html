Running a test against this host

From any host with perfSONAR tools installed:

pscheduler ping HOST_IP_OR_DOMAIM
pscheduler task latency    --dest HOST_IP_OR_DOMAIM
pscheduler task throughput --dest HOST_IP_OR_DOMAIM -t 10
pscheduler task trace      --dest HOST_IP_OR_DOMAIM

Throughput tests are rate and duration limited. Please keep runs short and infrequent.
